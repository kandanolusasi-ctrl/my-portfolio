M.TECH MAJOR PROJECT2026

VeriRAG

Beyond Retrieval: Claim-Level Hallucination Detection, Citation Verification and Repair for Trustworthy Domain-Specific Retrieval-Augmented Question Answering

A document-grounded RAG workflow designed to improve answer trustworthiness. It retrieves evidence from PDF documents, generates answers, extracts answer claims, checks claim support using Natural Language Inference (NLI), retrieves citation evidence and supports evidence-based answer repair.
