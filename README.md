# M.Tech CSE Portfolio Website

A responsive, modern dark-theme personal portfolio built with HTML, CSS and JavaScript. It is ready for GitHub Pages.

## 1. Personalize before publishing

Open `index.html` and replace these placeholders:

- `Your Name` / `YourName` — your preferred display name
- `your.email@example.com` — your professional email
- `your-linkedin` — your LinkedIn profile slug
- `your-github` — your GitHub username
- Update the undergraduate degree, college and graduation year
- Add your verified certifications and resume link when ready

Also update the `Y` monogram in the header/footer if you want a different initial.

## 2. Preview on your computer

Open `index.html` in Chrome or Edge. All three files (`index.html`, `style.css`, `script.js`) must stay together in the same folder.

## 3. Publish free with GitHub Pages

1. Sign in to https://github.com/ or create an account.
2. Create a new **public** repository. A good name is `yourusername.github.io` for a personal site, or `my-portfolio` for a project site.
3. Upload `index.html`, `style.css`, and `script.js` to the repository root (not inside another folder).
4. Open repository **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait for the deployment to finish. GitHub will show the published website URL in the Pages section.

For a repository named `yourusername.github.io`, the URL is usually `https://yourusername.github.io/`. For another repository name, it is usually `https://yourusername.github.io/my-portfolio/`.

## Notes

- No backend or paid hosting is required.
- The Google Fonts import needs an internet connection; the site still works with fallback fonts if it is unavailable.
